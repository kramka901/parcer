# 🏫 Бот и парсер расписания и замен уроков Tallinna Mustjõe Gümnaasium (www.mjg.ee)

Официальный полнофункциональный бот расписания и замен для **Tallinna Mustjõe Gümnaasium** (система EduPage `mustjoe.edupage.org`).

---

## 🌟 Новые и основные возможности

1. **🚪 Кабинеты преподавателей и школьная навигация:**
   - Для каждого учителя отображается **основной кабинет**, а также все кабинеты, где он преподаёт, с разбивкой по дням недели, классам и предметам.
   - Команда `/room <номер>` (напр. `/room 204`) — детальное расписание любого кабинета школы и список учителей, проводящих там занятия.
   - Команда `/rooms` — единый справочник всех кабинетов школы с закреплёнными учителями.
   - Команда `/freerooms` — свободные кабинеты прямо сейчас в текущий урок (где можно позаниматься или провести консультацию).
   - Команда `/whereis <учитель>` — где прямо сейчас находится преподаватель (текущий урок, класс, кабинет или перемена).
   - Интерактивные кнопки «🚪 Кабинеты учителя» и «🔍 Где сейчас?» в меню преподавателя.

2. **💬 Полноценная работа в групповых чатах и беседах классов:**
   - **Отдельная команда вызова бота:** `/bot` (а также `/call`, `/mjg`, `/parcer`, `/расписание`).
   - При вызове `/bot` в группе открывается специальная панель управления беседой с удобными кнопками:
     «📅 Сегодня», «📆 Завтра», «🗓 Вся неделя», «🔄 Замены», «🚪 Свободные кабинеты», «👩‍🏫 Учителя» и «🏫 Привязать класс».
   - Команда `/setclass <класс>` в группе привязывает класс к беседе (напр. `/setclass 8K`).
   - **Умная фильтрация сообщений (Anti-Spam):** бот в беседах НЕ спамит на обычные разговоры участников. Он отвечает только при вызове команд (`/bot`, `/today` и др.), упоминании через `@имя_бота`, ответе на сообщение бота (reply) или фразах вида `«бот 8K»`, `«бот замены»`, `«бот где Кулакова»`.
   - **Авто-уведомления для бесед:** новые замены для привязанного класса автоматически приходят прямо в групповой чат!

3. **💾 Гарантия сохранения базы пользователей (97 пользователей) и динамический учёт:**
   - При обновлении кода и перезапусках бота **все 97 пользователей надёжно сохраняются** в постоянной базе `user_preferences.json` с автоматическим резервным копированием `.bak`.
   - **Точный учёт при выходе/блокировке:** если пользователь заблокировал бота, удалил диалог или написал `/stop` (`/leave`), статус пользователя мгновенно меняется на неактивный, а **счётчик активных пользователей корректно уменьшается**.
   - При разблокировке или отправке `/start` счётчик автоматически увеличивается.
   - При отправке уведомлений и рассылок заблокировавшие пользователи автоматически выявляются и деактивируются.
   - Команда администратора `/setusers <число>` позволяет при необходимости скорректировать базовое число.

4. **🔍 Универсальный школьный поиск (`/search <запрос>`) и подробная статистика (`/stats`):**
   - Команда `/search <запрос>`: мгновенный умный поиск по учителям, номерам кабинетов, классам и предметам (напр. `/search химия`, `/search 106`, `/search Кулакова`).
   - Команда `/stats`: наглядная статистика активных пользователей, отписавшихся, подключенных бесед, количества классов, учителей и статуса мониторинга.

5. **👑 Панель администратора и рассылка сообщений:**
   - Меню администратора (`/admin`): массовая рассылка с предпросмотром и защитой, управление админами (`/addadmin`, `/deladmin`, `/admins`), принудительное обновление кэша.

6. **👥 Поддержка подгрупп (физкультура мальчики/девочки, языковые группы):**
   - Индивидуальная фильтрация в профиле (`/profile`), поддержка сдвоенных уроков.

7. **🔄 Мониторинг замен в реальном времени:**
   - Автоматическая проверка замен каждые 3 минуты и моментальные оповещения.

## 🤖 Список команд бота

### Пользовательские команды
| Команда | Описание |
| :--- | :--- |
| `/start` | Главное интерактивное меню |
| `/bot [запрос]` | Призыв бота в беседах и группах (или интерактивная панель чата) |
| `/profile` (или `/role`) | Настройки профиля, выбор подгрупп (мальчики/девочки) и уведомлений |
| `/today [класс/учитель]` | Расписание и замены на сегодня |
| `/tomorrow [класс/учитель]` | Расписание и замены на следующий рабочий день |
| `/schedule [класс]` | Расписание уроков на всю неделю |
| `/teacher [фамилия]` | Расписание уроков учителя (классы, кабинеты, замены) |
| `/teachers` | Список всех преподавателей школы |
| `/room <номер>` | Расписание кабинета и список учителей, преподающих в нём |
| `/rooms` | Справочник всех кабинетов школы с учителями |
| `/freerooms` | Свободные кабинеты прямо сейчас в текущий урок |
| `/whereis <учитель>` | Где прямо сейчас находится преподаватель (урок, класс, кабинет) |
| `/search <запрос>` | Универсальный быстрый поиск (учитель, класс, кабинет, предмет) |
| `/stats` | Подробная статистика пользователей и работы бота |
| `/substitutions [класс]` | Актуальные замены уроков |
| `/classes` | Список всех классов (1A – 12C) |
| `/setclass <класс>` | Сохранить свой класс (в группе — привязать класс к беседе) |
| `/setteacher <фамилия>` | Зарегистрироваться как учитель |
| `/notify` | Включить / выключить авто-уведомления |
| `/stop` (или `/leave`) | Отписаться и выйти из бота (уменьшает счётчик активных) |
| `/help` | Подробная справка по командам |

### Команды администратора
| Команда | Описание |
| :--- | :--- |
| `/admin` | Открыть отдельную панель администратора |
| `/broadcast [текст]` | Создать массовую рассылку для всех пользователей |
| `/setusers <число>` | Установить целевое базовое количество пользователей (напр. 97) |
| `/addadmin <ID>` | Назначить пользователя администратором |
| `/deladmin <ID>` | Удалить администратора |
| `/admins` | Показать список администраторов |
