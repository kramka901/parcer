# 🏫 Парсер расписания и замен уроков для сайта https://www.mjg.ee

Бот и парсер для **Tallinna Mustjõe Gümnaasium** (Таллиннская Мустйыэская гимназия, сайт [www.mjg.ee](https://www.mjg.ee), система EduPage `mustjoe.edupage.org`).

Парсер извлекает:
1. 📚 **Базовое расписание уроков** для всех классов (1A – 12C), включая время начала и окончания звонков, названия предметов, кабинеты и фамилии преподавателей.
2. 🔄 **Актуальные замены и отмены уроков** на сегодня, завтра или любую выбранную дату напрямую из системы EduPage.
3. 📅 **Объединенный просмотр дня** — накладывает актуальные замены поверх базового расписания класса и подсвечивает изменения.

## 🚀 Быстрый старт

### 1. Получение токена Telegram-бота
1. Откройте Telegram и перейдите к [@BotFather](https://t.me/BotFather).
2. Напишите команду `/newbot`.
3. Задайте имя бота (например, `Mustjoe Schedule Bot`) и username (например, `mjg_schedule_bot`).
4. Скопируйте выданный токен вида: `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`.

### 2. Настройка токена
Откройте файл `.env` в этой папке:
```env
TELEGRAM_BOT_TOKEN=вставьте_сюда_ваш_токен
```

### 3. Установка зависимостей (при необходимости)
Зависимости уже установлены в вашей системе, но при необходимости можно выполнить:
```bash
pip install -r requirements.txt
```

### 4. Запуск проверки (тестирование парсера)
Вы можете запустить встроенный тест, чтобы убедиться, что парсер успешно считывает данные:
```bash
python test_parser.py
```

### 5. Запуск Telegram-бота
```bash
python bot.py
```
После запуска откройте вашего бота в Telegram и отправьте `/start`.

## 🤖 Команды Telegram-бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Главное меню с интерактивными кнопками |
| `/help` | Справка по всем командам |
| `/today [класс]` | Расписание и замены на **сегодня** (например `/today 10A`) |
| `/tomorrow [класс]` | Расписание и замены на **следующий учебный день** |
| `/schedule [класс]` | Базовое расписание уроков на неделю |
| `/substitutions [класс]` | Только замены уроков (на сегодня) |
| `/classes` | Список всех 35 классов школы |
| `/setclass <класс>` | Запомнить класс (например `/setclass 10A`), чтобы не вводить его каждый раз |
| `/stats` | Подробная статистика аудитории и школьной базы |
| `/accounts` (или `/users`) | **(Админ)** Просмотр сохранённых аккаунтов пользователей |
| `/history` (или `/events`) | **(Админ)** Журнал прихода и ухода пользователей с числом активных участников |
| `/admin` | **(Админ)** Панель управления ботом |
| `/broadcast <текст>` | **(Админ)** Рассылка сообщения всем пользователям |

## 🗄️ База данных SQLite и система учёта аккаунтов

Бот оснащён полноценной базой данных **SQLite** (`database.db`) с поддержкой режима высокой производительности WAL:

1. **Таблица `accounts`:**
   - Хранит аккаунты пользователей: Telegram ID, `@username`, имя и фамилию (`full_name`), язык, роль (`student` или `teacher`), выбранный класс или преподавателя, подгруппы физкультуры и иностранных языков, флаг уведомлений, активность (`is_active: 1/0`), причину деактивации, дату регистрации (`created_at`) и дату последней активности (`last_seen`).

2. **Таблица `user_events` (Журнал прихода и ухода пользователей):**
   - Фиксирует каждое событие:
     - `JOINED` — новый пользователь впервые запустил бота.
     - `RETURNED` — пользователь разблокировал бота или вернулся после отписки.
     - `BLOCKED` — пользователь заблокировал бота (отслеживается через Telegram `my_chat_member`).
     - `STOPPED` — пользователь отписался через команду `/stop`.
   - **Фиксация числа пользователей:** каждое событие сохраняет точное число активных пользователей (`active_users_count`) и общее число аккаунтов в базе (`total_users_count`) на момент события!

3. **Двусторонняя синхронизация:**
   - Данные автоматически мигрируют из существующих файлов `user_preferences.json`, `admins.json`, `chats_preferences.json`.
   - Настройки также синхронизируются обратно в JSON для создания резервных копий.

## 💡 Особенности и возможности

- **Интерактивные кнопки (Inline Keyboards):** Бот полностью управляется кнопками — можно выбрать возрастную группу (1-4, 5-9, 10-12 классы), нужный класс и переключать дни недели (Пн, Вт, Ср, Чт, Пт) в один клик.
- **Интеллектуальный расчет дат:** В пятницу или на выходных команда "На завтра" автоматически покажет расписание на понедельник.
- **Быстрое кэширование:** Расписание кэшируется в оперативной памяти, поэтому кнопки работают мгновенно без повторных медленных запросов к сайту.
- **Сохранение предпочтений:** Бот запоминает выбранный класс пользователя в `user_preferences.json`.
