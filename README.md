# 🏫 Бот и парсер расписания и замен уроков Tallinna Mustjõe Gümnaasium (www.mjg.ee)

Официальный полнофункциональный бот расписания и замен для **Tallinna Mustjõe Gümnaasium** (система EduPage `mustjoe.edupage.org`).

---

## 🌟 Новые и основные возможности

1. **👑 Панель администратора и рассылка сообщений:**
   - Отдельное меню администратора (`/admin` или кнопка «👑 Меню администратора»).
   - **Массовая рассылка сообщений всем пользователям** бота с предпросмотром, подтверждением, защитой от спама и отчётом о доставке (сколько доставлено, сколько заблокировали бота).
   - **Управление администраторами прямо через интерфейс бота** или команды (`/addadmin <ID>`, `/deladmin <ID>`, `/admins`). Добавлять новых админов можно мгновенно.
   - Детальная статистика пользователей и кнопка мгновенного обновления кэша с EduPage.

2. **👩‍🏫 Расписание уроков для учителей (классы и кабинеты):**
   - Учителя могут смотреть свои уроки на сегодня, завтра, неделю и свои замены.
   - **Ученики и родители также могут посмотреть расписание любого учителя** (команда `/teacher <фамилия>` или кнопка «👩‍🏫 Расписание учителей»).
   - В каждом уроке чётко отображаются: **класс (например, 8K), кабинет (например, каб. 122), предмет, время звонков и подгруппа**.

3. **👥 Поддержка подгрупп (физкультура мальчики/девочки, языковые группы):**
   - Уроки с делением на группы чётко подписаны: `👦 Мальчики`, `👧 Девочки`, `👥 1 группа`, `👥 2 группа`, `🇩🇪 Немецкий яз.`, `🇫🇷 Французский яз.`
   - В профиле (`/profile` -> «👥 Настройка подгрупп») каждый ученик может выбрать свою подгруппу (например, мальчик или девочка, 1-я или 2-я группа), и расписание автоматически отфильтрует только нужные уроки!
   - Доступен режим «Все (без фильтра)» для просмотра всех групп класса одновременно.

4. **🔄 Актуальные замены и отмены уроков:**
   - Моментальная загрузка замен на сегодня, завтра и любой день.
   - Фоновый мониторинг новых замен каждые 3 минуты с авто-оповещением учеников и учителей.
   - Надежное локальное кэширование: бот работает даже при сбоях сети или недоступности EduPage.

## 🤖 Список команд бота

### Пользовательские команды
| Команда | Описание |
| :--- | :--- |
| `/start` | Главное интерактивное меню |
| `/profile` (или `/role`) | Настройки профиля, выбор подгрупп (мальчики/девочки) и уведомлений |
| `/today [класс/учитель]` | Расписание и замены на сегодня |
| `/tomorrow [класс/учитель]` | Расписание и замены на следующий рабочий день |
| `/schedule [класс]` | Расписание уроков на всю неделю |
| `/teacher [фамилия]` | Расписание уроков учителя (классы и кабинеты) |
| `/teachers` | Список всех преподавателей школы |
| `/substitutions [класс]` | Актуальные замены уроков |
| `/classes` | Список всех классов (1A – 12C) |
| `/setclass <класс>` | Сохранить свой класс (например, `/setclass 8K`) |
| `/setteacher <фамилия>` | Зарегистрироваться как учитель |
| `/notify` | Включить / выключить авто-уведомления |
| `/help` | Подробная справка по командам |

### Команды администратора
| Команда | Описание |
| :--- | :--- |
| `/admin` | Открыть отдельную панель администратора |
| `/broadcast [текст]` | Создать массовую рассылку для всех пользователей |
| `/addadmin <ID>` | Назначить пользователя администратором |
| `/deladmin <ID>` | Удалить администратора |
| `/admins` | Показать список администраторов |
